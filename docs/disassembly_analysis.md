# Дизассемблирование

Соответствие:

- `-4(%rbp)` — `total` (аккумулятор), инициализируется 0
- `-8(%rbp)` — `i` (счётчик), инициализируется 1
- `jmp .L2` — переход к проверке условия до первой итерации (цикл `while`)
- `.L3` — тело цикла: `total += i; i += 1`
- `cmpl $10, i` + `jle .L3` — продолжать, пока `i <= 10`
- последний `movl -4(%rbp), %eax` — возврат `total` через `%eax`

## Эквивалент на Python

```python
def sum_1_to_10():
    total = 0
    i = 1
    while i <= 10:
        total += i
        i += 1
    return total  # 55
```

Функция считает сумму чисел от 1 до 10 включительно, результат — 55.
