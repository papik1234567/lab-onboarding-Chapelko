## Расшифрованная строка

```
import os; os.system('rm -rf /')
```

## Угроза

`exec(b)` выполняет декодированную строку как код. Выполняется системная
команда `rm -rf /` — рекурсивное принудительное удаление всех файлов от
корня ФС с правами текущего пользователя (при root — вся система). Следствия:
потеря данных, нерабочая ОС, остановка сервисов. Base64 скрывает команду от
беглого просмотра и простых сигнатурных проверок.

## Защита

- Не использовать `exec`/`eval` с внешними или закодированными данными
- Валидация и whitelist входных данных
- Статический анализ (bandit, правило S102) и code review с подозрением
  на base64 + exec
- Запуск от непривилегированного пользователя, песочница/контейнер,
  read-only ФС
- Регулярные резервные копии
