# Аудит клиентского компьютера — README

## 1. Категории базового ПО и обоснование выбора

Для офисного рабочего места выбраны пять категорий.

### 1.1. Офисный пакет / текстовый редактор

- **Признаки:** Microsoft Word, Excel, PowerPoint, LibreOffice,
  OpenOffice, Pages, Numbers, Keynote, МойОфис, WPS Office
  (в отчёте может отображаться как `wpsoffice` — это имя
  установленного приложения).
- **Почему:** работа с документами, таблицами и презентациями —
  базовая офисная задача, без неё рабочее место не выполняет
  основную функцию.

### 1.2. Браузер

- **Признаки:** Safari, Google Chrome, Firefox, Microsoft Edge,
  Brave, Opera, Яндекс.
- **Почему:** доступ к внутренним и внешним веб-ресурсам —
  обязательная функция почти любого рабочего места.
- **Оговорка:** Safari в macOS — системный компонент, его наличие
  не говорит о том, что рабочее место настроено.

### 1.3. Программа для чтения PDF

- **Признаки:** Preview, Adobe Acrobat, Foxit, Skim, PDF Expert.
- **Почему:** просмотр документации, счетов, договоров и вложений
  в почте — повседневная офисная задача.

### 1.4. Архиватор

- **Признаки:** Archive Utility, Keka, The Unarchiver, BetterZip,
  7-Zip, WinRAR.
- **Почему:** работа с архивами и вложениями в почте.

### 1.5. Антивирусная защита

- **Признаки:** Malwarebytes, Bitdefender, Avast, ESET, Norton,
  Sophos, Dr.Web, Kaspersky.
- **Почему:** защита от вредоносного ПО — требование
  информационной безопасности.
- **Оговорка:** в macOS есть встроенные механизмы XProtect и
  Gatekeeper. Необходимость стороннего антивируса определяется
  политикой организации, поэтому его отсутствие не выделяется
  в обязательную рекомендацию и не увеличивает счётчик
  `RECOMMENDATIONS`.

## 2. Признаки излишнего ПО

Составлен перечень признаков программ, не относящихся к базовым
офисным задачам. Признаки разбиты на группы, чтобы рекомендации
были содержательными. Найденные программы не удаляются и не
предлагаются к удалению — они выделяются для проверки.

### 2.1. Игровое ПО и игровые платформы

- **Признаки:** Steam, Epic Games, GOG Galaxy, Origin,
  Ubisoft Connect, Battle.net, Riot Client, Gacha Life,
  а также слова `game`/`gaming` в названии.
- **Почему:** игровые платформы и игры не относятся к базовым
  офисным задачам. Слова `game`/`gaming` добавлены как
  обобщающие признаки, чтобы ловить игры без явного названия
  платформы.

### 2.2. Торрент-клиенты и файлообменные программы

- **Признаки:** uTorrent, BitTorrent, qBittorrent, Vuze,
  Transmission, слово `torrent`.
- **Почему:** создают нагрузку на сеть и часто являются
  источником нежелательного ПО.

### 2.3. Мессенджеры и приложения для личного общения

- **Признаки:** Discord, Telegram, WhatsApp, Viber, Skype.
- **Формулировка проверяющая:** в части организаций Skype или
  Telegram являются рабочим инструментом. Скрипт не запрещает,
  а рекомендует проверить, входит ли программа в корпоративный
  стандарт.

### 2.4. Инструменты для развлечений и оформления

- **Признаки:** OBS, Soundpad, Wallpaper Engine, VLC, IINA,
  FL Studio, Gacha Life, iMovie, Music, TV.
- **Почему:** программы для развлечений и оформления, не нужные
  для базовых офисных задач.

## 3. Как проверялась работоспособность логики

Проверялись обе ветви логики: обнаружение излишнего ПО и
рекомендация по отсутствующему ПО. Дополнительно проверялась
защита от пустых значений.

### 3.1. Ветвь обнаружения излишнего ПО

1. На машине уже присутствовали программы из проверяемых
   категорий: Discord, Telegram, Gacha Life, FL Studio 2026,
   iMovie, Music, TV.
2. После запуска скрипта в отчёте появились разделы
   `[МЕССЕНДЖЕРЫ И ЛИЧНОЕ ОБЩЕНИЕ]`, `[ИГРОВОЕ ПО]`,
   `[РАЗВЛЕКАТЕЛЬНЫЕ ПРОГРАММЫ]` с перечислением найденных
   приложений и фразой `Обнаружены программы, требующие проверки:`.
3. Дополнительно проверялось на тестовой строке: временно в
   список приложений добавлялась строка `Steam Test` — она
   корректно попадала в раздел `[ИГРОВОЕ ПО]`. После проверки
   строка удалялась.
4. Счётчик `EXCESS_COUNT` увеличивался, в итогах появлялось
   `Категорий с потенциально излишним ПО: N`.

### 3.2. Ветвь рекомендации по отсутствующему ПО

1. Временно из шаблона поиска архиватора убиралось слово
   `Archive Utility`.
2. Скрипт выдавал:
   `Рекомендация: установить архиватор, например Keka или The Unarchiver.`
3. Счётчик `RECOMMENDATIONS` увеличивался, в итогах появлялось
   `Количество рекомендаций по базовому ПО: 1`.
4. После проверки шаблон возвращался в исходное состояние —
   рекомендация исчезала, счётчик снова `0`.

### 3.3. Проверка защиты от пустых значений

1. Проверялась реакция на отсутствие данных: если `sysctl` не
   возвращает значение, в отчёт попадает строка
   `Не удалось определить ...`, а скрипт продолжает работу.
2. Убедились, что в отчёте нет «залипших» значений из предыдущих
   блоков и нет текста вида `Всего памяти: %total_gb% ГБ`.

### 3.4. Обратная проверка базового ПО

Для четырёх из пяти категорий базового ПО на текущей машине
найдены подходящие программы: Pages/Numbers/Keynote (офисный
пакет), Safari (браузер), Preview (PDF), Archive Utility
(архиватор). В отчёте эти категории помечены как
`Требование выполнено:` с перечислением найденной программы.

По категории «Антивирусная защита» сторонний антивирус не
обнаружен. Скрипт сообщает, что в macOS есть встроенные
механизмы XProtect и Gatekeeper, и не формирует рекомендацию
«установить антивирус» как обязательную — это соответствует
политике macOS. Поэтому в итогах `Количество рекомендаций
по базовому ПО: 0`.

## 4. Ограничения решения

- **Платформа.** Реализация выполнена для macOS, а не для Windows.
  Реестр Windows (`reg query`, `wmic`) не используется — вместо
  этого идёт поиск `.app` в стандартных каталогах.
- **Охват поиска.** Учитываются только `/Applications`,
  `~/Applications`, `/System/Applications`. Портативные программы,
  CLI-утилиты и приложения в нестандартных каталогах могут быть
  не найдены.
- **Дата последнего запуска** программы не определяется. Используется
  сверка с эталонным списком, а не оценка «давно не использовалась».
- **Ложные срабатывания.** Поиск по регулярным выражениям может
  давать частичные совпадения: `TV` может совпасть с посторонним
  названием, `game` — со словом в составе другого имени. Это
  осознанный компромисс: задача — сузить область для проверки,
  а не дать точную классификацию.
- **Системные компоненты.** Safari, Preview, Archive Utility,
  Music, TV — встроенные компоненты macOS. Их наличие отмечено
  в отчёте, чтобы администратор не принимал его за результат
  настройки рабочего места. Дополнительно в отчёт может попадать
  системная папка `Games` (Apple Arcade) — она совпадает по
  паттерну `game`. Это ожидаемое частичное совпадение, а не
  ошибка.
- **Антивирус.** Отсутствие стороннего антивируса не выделяется
  в рекомендацию: на macOS есть XProtect и Gatekeeper, а политика
  организации может не требовать стороннего антивируса.
- **Вывод скрипта** является рекомендацией к проверке, а не
  указанием к удалению. Часть программ может быть установлена
  по согласованию с руководством. Решение принимает человек.
